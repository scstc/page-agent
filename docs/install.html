淘未来 Web Agent

让 AI 替你淘每一个网页

1 显示收藏夹栏
Ctrl + Shift + B 或 ⌘ + Shift + B
2 拖拽下面按钮到收藏夹栏
✨WebAgent
点击不会启动；请用鼠标按住按钮拖到收藏夹栏
3 在其他网站点击收藏夹中的按钮即可使用

本地模式需先跑 npm run dev:demo:https，并已通过 npm run setup:dev-certs 信任 mkcert 自签证书。
测试 / 生产模式的脚本已上传至 OSS，点击书签会先弹口令对话框，从 OSS 拉 SHA-256 哈希列表比对，正确后才注入 web-agent 脚本。
